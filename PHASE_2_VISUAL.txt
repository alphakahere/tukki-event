┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  👑 OWNER (Full Control)
     ✓ Delete organization
     ✓ Manage all members
     ✓ Invite other owners
     ✓ Update organization settings
     ✓ All admin permissions

  🎯 ADMIN (Management)
     ✓ Update organization settings
     ✓ Invite members (except owners)
     ✓ Manage STAFF members
     ✓ Remove STAFF members
     ✗ Cannot remove other admins or owner

  📋 STAFF (Contributor)
     ✓ View organization
     ✓ View members
     ✓ Create events (Phase 3)
     ✗ Limited management permissions

1️⃣  Create Organization:
    POST /api/v1/organizations
    {
      "name": "Tech Events Inc",
      "description": "We organize amazing tech events"
    }

2️⃣  List Organizations:
    GET /api/v1/organizations
    
    Response: [
      {
        "id": "...",
        "name": "Tech Events Inc",
        "slug": "tech-events-inc",
        "memberCount": 5,
        "eventCount": 12,
        "userRole": "OWNER"
      }
    ]

3️⃣  Invite Member:
    POST /api/v1/organizations/:id/members
    {
      "email": "member@example.com",
      "role": "ADMIN"
    }

4️⃣  List Members:
    GET /api/v1/organizations/:id/members
    
    Response: [
      {
        "id": "...",
        "role": "OWNER",
        "user": {
          "email": "owner@example.com",
          "firstName": "John",
          "lastName": "Doe"
        }
      }
    ]

5️⃣  Update Member Role:
    PATCH /api/v1/organizations/:id/members/:userId
    {
      "role": "STAFF"
    }
