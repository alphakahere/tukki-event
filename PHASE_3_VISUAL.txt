  1️⃣  DRAFT
      ├─ Event created
      ├─ Not visible publicly
      ├─ Only org members can see
      └─ Can add tickets

  2️⃣  PUBLISHED
      ├─ Event goes live
      ├─ Visible to everyone
      ├─ Requires ≥ 1 ticket type
      └─ Can accept registrations

  3️⃣  ONGOING
      ├─ Event currently happening
      └─ Real-time updates

  4️⃣  COMPLETED
      ├─ Event finished
      └─ Historical record

  ❌ CANCELLED
      └─ Event cancelled
